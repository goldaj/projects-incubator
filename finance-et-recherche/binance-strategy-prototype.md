# Prototype de stratégie Binance

**Stade : code historique de stratégie et de backtest, sans validation économique revendiquée.**

Les sources comprennent utilitaires Binance, manipulation CSV, logique de stratégie et variantes de backtest. Leur archive propre est le dépôt privé `binance-strategy-prototype`.

Les identifiants et fichiers de données restent externes au dépôt. Les vérifications de préparation portent sur syntaxe, configuration locale et absence des anciennes valeurs privées dans Git. Aucun appel Binance ni ordre n'a été exécuté pendant cette préparation.

Prochaines étapes : dépendances reproductibles, tests hors réseau, revue des permissions et des opérations d'ordre, datasets redistribuables et méthode de backtest chronologique avec coûts explicites. Le code ancien n'est pas présenté comme une stratégie rentable ou prête à déployer.

# Applications de formation Angular

Stade : **archives pédagogiques** issues d’une formation, avec squelette généré par Angular CLI 8.3.12.

- `angular-first-app` (sources préparées localement, publication GitHub en attente) explore composants, directives, services et modules.
- `angular-todo-list` (sources préparées localement, publication GitHub en attente) explore navigation, formulaires, API HTTP de démonstration et tests.

L’historique Git local existant a été conservé. Les deux sauvegardes locales de chaque projet étaient identiques et sont représentées par un seul dépôt.

Suites : remettre à niveau Node, Angular et les dépendances ; exécuter les anciens tests puis vérifier les parcours dans un navigateur. Le code et les versions historiques servent de point de départ ; ces applications ne sont pas déclarées compatibles avec l’outillage actuel.

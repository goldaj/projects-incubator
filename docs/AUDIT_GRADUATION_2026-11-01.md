# Audit des fiches d'incubation — 1er novembre 2026

**Méthode :** comparaison des 18 fiches de projet actives de l'incubateur avec la liste de 42 dépôts GitHub accessibles et leurs README. L'identité du besoin a été privilégiée plutôt que la ressemblance de nom ou de domaine.

**Résultat : 18 fiches examinées, aucune duplication exacte confirmée, aucune fiche supprimée.**

Les cas susceptibles d'être confondus ont été examinés :
- la toile géographique en réalité augmentée vise des contributions partagées et persistantes, et non la transformation architecturale ;
- le jeu d'échecs à apparences collectionnables respecte les règles classiques, alors que le jeu d'échecs existant est un roguelite ;
- le jeu où l'absence est valorisée est distinct du prototype de jeu incrémental classique ;
- l'outil de cohérence de récits entrelacés est distinct des outils de manuscrits et des exercices narratifs historiques ;
- les agents de simulation sociale ne sont pas l'assistant virtuel Jade ;
- l'agent de test de jeux est un outil transversal qui n'est pas déjà livré par un jeu existant.

Les projets antérieurement transférés vers un dépôt dédié ne figurent déjà plus dans les fiches actives ; le programme de recherche sur des brevets anciens est par exemple suivi dans son propre dépôt.

**Règle :** lors d'une promotion effective vers un dépôt autonome, déplacer les documents et leur contexte utile vers la destination, puis supprimer dans le même flux l'ancienne fiche d'idée et son lien de navigation. Ne pas supprimer une idée sur simple intuition ; vérifier la fonction réelle et l'état du dépôt. Les anciennes versions demeurent accessibles via l'historique Git, sans être des fiches actives.

Cet audit est documentaire ; aucune compilation ni inspection exhaustive de chaque branche n'est revendiquée.

# Prototypes de jeux Python

Stade : **prototypes exploratoires**, avec une qualité et une complétude variables.

Les sources sont regroupées dans `python-game-prototypes` (sources préparées localement, publication GitHub en attente), qui constitue leur source de vérité. Ce regroupement évite un dépôt par petit essai et permet de comparer plusieurs boucles de jeu : livraison et exploration dans Poste-Slime, placement de pièces dans Pixel Patchwork, Pong, traversée, labyrinthe, plateforme procédurale et tower defense.

Plusieurs versions ont été réalisées avec l’aide d’une IA. Le dépôt conserve les attributions des sources et ne les présente pas comme des jeux finalisés.

Les suites utiles sont de vérifier les boucles complètes de jeu, consigner commandes et dépendances par prototype, mesurer le ressenti et les difficultés, puis choisir les pistes qui justifient un projet autonome. Les sauvegardes personnelles et environnements restent locaux.
